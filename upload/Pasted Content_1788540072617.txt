==================================================
AUTHORITATIVE GOAL
==================================================

The current website caches DATA, but public pages still execute/render on each request.

CURRENT:

    request
      ↓
    execute page
      ↓
    read cached data
      ↓
    assemble/render UI
      ↓
    response

THIS IS NOT THE TARGET.


TARGET:

    first request for a cacheable public route
      ↓
    execute page
      ↓
    load required data
      ↓
    render complete UI
      ↓
    cache rendered page/component result

    subsequent requests
      ↓
    reuse cached rendered result
      ↓
    DO NOT execute/assemble the page again


When relevant underlying data changes:

    data mutation
      ↓
    existing domain event
      ↓
    existing tag mapping
      ↓
    specific cache tag invalidation
      ↓
    affected cached UI/page output becomes stale
      ↓
    next access regenerates affected output
      ↓
    fresh rendered result is cached again


This is the architecture to implement.
